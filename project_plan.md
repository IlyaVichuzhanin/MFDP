Проект по созданию рекомендательной системы товаров.


1.  Бизнес-анализ (Business Understanding)

- Цель проекта: Создать рекоомендательную систему товаров с целью повышения продаж магазина/сервиса.
- Аналоогичные решения существуют, но являются коммерческой тайной и недоступны для других магазинов/сервисов. Цель создания данного решения в первую очередь создать более совершенное решение учитывающие разные аспекты потребительских характеристик (сезонную составляющую и прошлые покупки пользователя).

1.1 Текущая ситуация (Assessing current solution)
- Ресурсов для создания проекта достатоочно. Планируется использовать бесплатные ресурсы Google Colab
- Поиск данных еще планируется, но предварительно подобные датасэты не  редкость для kagle и пр. платформ.
- Дополнительные эксперты не предпоолаагаются.

Риски:

- Недостаточность/невалидность данных.
- Сжатые сроки проекта.
